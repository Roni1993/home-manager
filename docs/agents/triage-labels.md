# Triage Labels

Labels used by the `/triage` skill to move issues and external PRs through a state machine.

## Vocabulary

- `needs-triage` — new or incoming; not yet categorised
- `needs-info` — awaiting information from the reporter
- `ready-for-agent` — verified and briefed; safe for an agent to act on
- `ready-for-human` — needs a human decision or action
- `wontfix` — closed as intentionally not being addressed
