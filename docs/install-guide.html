1 BIOS flash → v2405 YOU

Goal: update BIOS from v0503 (Feb 2021) to v2405 (Dec 2025). Takes ~5 min.

  1. Power on (or reboot). Immediately mash Del to enter BIOS.
  2. Press F7 for Advanced mode.
  3. Go to the Tool tab → ASUS EZ Flash 3.
  4. Navigate to the USB drive (sdf3) and select ROG-STRIX-B560-I-GAMING-WIFI-ASUS-2405.CAP.
  5. Confirm the flash. Do not power off or unplug — ~5 minutes. The board reboots itself.
  6. After reboot, re-enter BIOS (Del) and confirm version shows v2405.

If the .CAP doesn't appear: it may need renaming — run BIOSRenamer.exe on the USB from Windows first, then retry. Stop and ask the agent if it still fails.

1b BIOS performance settings YOU

Goal: while you're in the BIOS (after the flash), set these once. They matter for this hardware: RTX 3060 Ti (ReBAR), DDR4 (XMP), and later KVM/VMs (VT-x/VT-d). All are safe defaults for a gaming box.

  1. XMP (RAM at rated speed) — big free performance win.
    • F7 Advanced → Ai Tweaker tab → Ai OverClock Tuner → XMP I
    • Pick XMP I (XMP II only if your RAM kit's XMP II profile exists and I is unstable).
    • If XMP makes boot fail or crash, re-enter BIOS and set Ai OverClock Tuner back to Auto.
  2. Re-Size BAR (Resizable BAR) + Above 4G Decoding — helps the RTX 3060 Ti.
    • Advanced tab → PCI Subsystem Settings → Above 4G Decoding = Enabled
    • Same page → Re-Size BAR Support = Enabled
  3. VT-x and VT-d — needed later for KVM/Podman/QEMU dev VMs.
    • Advanced tab → CPU Configuration → Intel (VMX) Virtualization Technology = Enabled
    • Advanced tab → System Agent (SA) Configuration → VT-d = Enabled
  4. CSM (Compatibility Support Module) = Disabled — CachyOS installs UEFI; pure-UEFI boot is cleaner.
    • Boot tab → CSM → Disabled (if present on this BIOS)
  5. Boot order — set the USB first so the installer boots cleanly, then it'll use the NVMe after install.
    • Boot tab → Boot Option Priorities
  6. Secure Boot — leave Disabled (CachyOS works fine without it; avoids enrollment hassle).

Press F10 → Save & Exit when done. If the system won't boot after XMP, re-enter BIOS and revert Ai OverClock Tuner to Auto — everything else is safe to leave on.

Skip anything that isn't present on this BIOS version — menu names vary slightly across ASUS boards. The three that really pay off: XMP, Re-Size BAR, VT-x/VT-d.

2 Install CachyOS YOU

Goal: install CachyOS on the 2TB NVMe. The 4TB HDD stays completely untouched.

  1. Boot from the USB (choose it in the boot menu, F8). Choose CachyOS at the GRUB menu.
  2. Wait for the live desktop (KDE), then launch Calamares (the installer).
  3. In Partitioning, select manual, target the 2TB NVMe only:
    • /boot/efi — 1 GB, fat32 (EFI System Partition)
    • / — rest of NVMe, Btrfs
  4. Do not touch the 4TB HDD. If Calamares offers to wipe it — decline.
  5. User: roni (full name: Roman). Set a strong password.
  6. Locale/timezone: your choice; keyboard: us.
  7. Let the install finish, then reboot.

3 First boot into KDE YOU

  1. Reboot and remove the USB when prompted.
  2. At the SDDM login screen, keep KDE/Plasma selected (it's the default).
  3. Log in as roni.
  4. Open Konsole (terminal).

4 Run bootstrap AGENT

Hand this off to the agent on the box. The command it runs (as roni):

curl -sL https://raw.githubusercontent.com/Roni1993/fleek/main/bootstrap.sh | bash

This installs: NVIDIA drivers → cachyos-gaming-meta, gamescope-session-cachyos, hyprpolkitagent, Determinate Nix, flakes — and mounts the 4TB HDD read-only at /mnt/staging (no wipe, no reformat).

If it fails partway: the box stays recoverable (home-manager switch --rollback / re-run). Don't panic — tell the agent what you see.

5 Verify + restore AGENT

  • SDDM sessions present: Hyprland, Plasma/KDE, Steam Big Picture (gamescope)
  • NVIDIA driver: nvidia-smi → expect 610.43.03
  • HDD mounted read-only at /mnt/staging (correct UUID in fstab)
  • SSH key rotated: new ed25519 on GitHub + Pi, paper/QR backup of new key + age key
  • Restored keys + Firefox profile from /mnt/staging/backup-for-cachyos
  • Resolution comment posted on ticket #7, then closed

6 Start the agent YOU → AGENT

Goal: get the agent running on the box. The repos are already cloned by bootstrap — no manual git clone needed.

  1. Add your token (one-time). In a new Konsole: 
    opencode auth login
    …and follow the prompts to add your API provider token/key.
  2. Auth for private repos (homelab, gameServerHosting). The gaming profile sets git's credential helper to gh, so: 
    gh auth login
    …then (if any private clones were skipped by bootstrap) re-run bootstrap or clone manually.
  3. Start the agent in a project. In ~/projects/fleek for ticket #7: 
    cd ~/projects/fleek && nix run .#agent
    Or open the agent in any other project (homelab, gameServerHosting, …): 
    nix run ~/projects/fleek#agent -- homelab
    (Same as cd ~/projects/<name> && opencode.)
  4. Point it at ticket #7 and the box-side handoff: 
    gh issue view 7
    …then tell the agent to read /tmp/opencode/handoff-box-session.md (or say "work wayfinder ticket 7, handoff at /tmp/opencode/handoff-box-session.md").

Projects cloned by bootstrap into ~/projects: fleek, homelab (private), gameServerHosting (private), JetBrainsBevy, pico-examples, steam-deck-controller — each on its usual branch.

After the token is in, the agent takes over from there — bootstrap, verify, SSH rotation, restore, and closing #7.

Troubleshooting

.CAP not shown in EZ Flash 3 → run BIOSRenamer.exe on the USB, retry. Still stuck? Stop, call the agent.
Calamares wants to wipe the HDD → decline. Only the NVMe gets partitioned.
Bootstrap aborts mid-way → re-run the curl command; it's idempotent. Box is recoverable at all times.
Can't reach this page on your phone → check phone/data, or open the same URL in a browser on the PC.
